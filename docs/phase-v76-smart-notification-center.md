# V76 — Smart notification center

## الهدف
تحسين مركز الإشعارات الحالي دون تغيير قواعد حفظ الإشعارات أو صلاحيات الوصول أو الاعتماد على خدمة Push.

## التغييرات
- إعادة تنظيم شاشة المركز إلى واجهة عربية واضحة بعنوان «مركز الإشعارات الذكي».
- فلاتر تفاعلية: الكل، غير المقروء، الحجوزات، الرسائل، وتنبيهات الحساب.
- بحث محلي في العنوان والنص ونوع الإشعار ضمن آخر 50 إشعاراً محمّلاً.
- تجميع زمني إلى اليوم، أمس، وسابقاً، مع إظهار حالة المقروء/الجديد والتصنيف والتاريخ.
- إبراز غير المقروء بصرياً، وإظهار عددها، مع خيار تحديد الكل كمقروء.
- تحديث القائمة بالسحب للأسفل وعند العودة إلى الشاشة.
- توجيه الإشعار المرتبط إلى مسار التفاصيل الحالي، مع منع فتح مزدوج متزامن.
- الإشعار غير المرتبط يظل قابلاً للتحديد كمقروء دون توجيه.

## المحافظة على السلوك السابق
- لا تغيير في API أو قاعدة البيانات أو أنواع الإشعارات أو تفضيلات Push.
- تبقى قراءة الإشعارات وتحديدها للمستخدم المصادق عليه فقط.
- لا يؤدي فشل فتح الوجهة إلى فقدان سجل الإشعار؛ ويُعرض الخطأ للمستخدم.
- لا يدّعي التصنيف الذكي فهم المحتوى طبياً؛ التصنيف مبني على نوع الإشعار ومعرّفات الوجهة.

## حدود التحقق
الاختبارات الثابتة تفحص عقود الواجهة وربط API والحالات الأساسية. لا تمثل بديلاً عن Expo bundle أو APK أو اختبار جهاز فعلي أو اختبار تكامل قاعدة البيانات.
