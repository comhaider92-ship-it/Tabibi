# V51 — رفع الصور والوثائق بصورة آمنة

## ما أضيف
- `upload_assets` لتسجيل الملفات الوصفية وربطها بحساب المالك والمنشأة عند الحاجة.
- `POST /api/v1/uploads` يقبل Base64 مع اسم الملف ونوعه وفئته؛ يقتصر على الطبيب أو مالك المنشأة بحسب الفئة.
- الفئات: صورة الطبيب، مؤهلات الطبيب (PDF)، صورة المنشأة، وثائق المنشأة (PDF).
- الصور JPEG/PNG/WebP بحد أقصى 5 MB، والوثائق PDF بحد أقصى 10 MB.
- فحص ترويسة الملف الفعلية، لا الاكتفاء بنوع MIME المرسل.
- أسماء تخزين عشوائية، تخزين خارج مجلد الويب العام، وصلاحيات ملفات 0600 ومجلد 0700.
- صور الطبيب والمنشأة لا تُعرض للعامة إلا بعد اعتماد ملف الطبيب أو المنشأة.
- الوثائق الخاصة لا تُعرض عبر مسار عام. المالك يستطيع تنزيل وثائق الاعتماد فقط أثناء بقاء ملف الطبيب/المنشأة بحالة pending، وصاحب الملف يستطيع تنزيل ملفاته.
- `GET /api/v1/uploads/mine` يعرض ملفات الحساب الحالي فقط.
- صورة الطبيب تربط تلقائياً بحقل `photoUrl`، وصورة المنشأة بحقل `imageUrl` وتظهر في دليل المنشآت.
- أضيفت دوال API للموبايل للرفع وعرض ملفات الحساب.

## واجهات API
- `POST /api/v1/uploads` — يتطلب JWT ودور doctor أو owner.
- `GET /api/v1/uploads/mine` — يتطلب JWT.
- `GET /api/v1/uploads/owner/review-queue` — للمالك فقط، ويعرض وثائق ملفات الطبيب/المنشأة التي ما زالت pending فقط.
- `GET /api/v1/uploads/:id/download` — يتطلب JWT وصلاحية صاحب الملف أو صلاحية مراجعة محدودة للمالك.
- `GET /api/v1/uploads/public/:id` — يعرض الصور فقط إذا كانت الجهة معتمدة.

## التشغيل
1. شغّل Migration `1733400000000-CreateSecureUploadAssets`.
2. عيّن `UPLOADS_DIRECTORY` إلى مسار دائم وخاص خارج أي public/static web root.
3. تأكد أن مستخدم تشغيل الخادم يستطيع الكتابة في المجلد وأن النسخ الاحتياطي يشمل الملفات.
4. اضبط حد جسم الطلب في reverse proxy إلى 14 MB على الأقل. الخادم يرفع حد JSON إلى 14 MB لدعم Base64.
5. عند نشر الخادم على عدة نسخ، استخدم تخزيناً مشتركاً خاصاً أو object storage متوافقاً؛ التخزين المحلي وحده لا يزامن الملفات بين النسخ.

## الحدود الحالية
- تمت إضافة واجهات الرفع في API client، لكن لم تتم إضافة منتقي ملفات Native داخل شاشات الموبايل في هذه المرحلة؛ يلزم دمج منتقي Expo واختباره على جهاز حقيقي.
- لا يوجد فحص مضاد للفيروسات أو تحويل/إزالة metadata للصور؛ يوصى بإضافتهما قبل الإطلاق العام.
- لم يتم اختبار قاعدة بيانات حقيقية أو بناء APK أو تشغيل رفع فعلي في هذه البيئة.
- يجب عدم نشر مجلد `private-uploads` كملفات static.
