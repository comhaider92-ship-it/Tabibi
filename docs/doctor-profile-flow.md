# ملف الطبيب ومراجعة المالك — V12

## الطبيب
- `POST /api/v1/doctors/me/profile` حفظ بيانات الملف.
- `GET /api/v1/doctors/me/profile` عرض الملف.
- `POST /api/v1/doctors/me/profile/submit` إرسال الملف للمراجعة.

## المالك
- `GET /api/v1/doctors/owner/pending` قائمة الملفات المنتظرة.
- `PATCH /api/v1/doctors/owner/:id/review` قرار الاعتماد أو الرفض.
مثال:
```json
{"decision":"approved","reviewNote":"تمت مراجعة البيانات"}
```

## دليل الأطباء العام
- `GET /api/v1/doctors?city=Basra&specialty=قلب`
- لا يعرض إلا الملفات المعتمدة.

## الحالات
- draft: مسودة الطبيب.
- pending: بانتظار مراجعة المالك.
- approved: يظهر في دليل الأطباء.
- rejected: مرفوض مع ملاحظة المالك.

أي تعديل على ملف معتمد يعيده إلى حالة pending حتى يراجعه المالك من جديد.

## حدود الإصدار
الشهادات مخزنة حالياً كنصوص وليست ملفات مرفوعة ومتحققاً منها. صورة الطبيب حقل URL فقط، وليس رفع ملفات. لم يتم تنفيذ نظام الدوام أو الفترات المتاحة بعد. يلزم ربط حساب الطبيب بملف طبي صحيح، والتحقق من صحة الشهادات ميدانياً قبل الاعتماد النهائي. لم يتم تشغيل NestJS أو PostgreSQL أو اختبارات تكامل.
