# V74 — مركز أمان الحساب ونشاط تسجيل الدخول

## ما أُنجز
- إضافة endpoint محمي `GET /auth/me/security/activity` لجميع الحسابات المسجلة.
- يعيد آخر 30 محاولة مرتبطة ببريد المستخدم أو هاتفه بعد اشتقاق HMAC بالمفتاح نفسه المستخدم في سجل V73.
- لا يعيد عنوان IP أو hash المعرف أو كلمة المرور أو OTP.
- لا يمكن للمستخدم طلب نشاط حساب آخر؛ الاستعلام مشتق حصراً من بيانات الحساب المستخرج من JWT.
- إضافة واجهة نشاط تسجيل الدخول في شاشة الملف الشخصي مع تحديث يدوي وتاريخ محلي.
- تبقى واجهة المالك المنفصلة لسجل الأحداث العامة كما هي.

## حدود السجل
يعرض هذا الإصدار الأحداث المسجلة بعد تفعيل جدول V73، ولا يستطيع إظهار أحداث أقدم أو تحديد الجهاز بدقة لأن النسخة السابقة لا تخزن هوية جهاز.
