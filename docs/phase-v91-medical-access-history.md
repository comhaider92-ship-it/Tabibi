# V91 — سجل الاطلاع والنشاط على الملف الصحي

## الهدف
تمكين المريض من مراجعة الأنشطة التي يسجلها النظام على ملفه الطبي، مع بيان نوع النشاط والجهة المنفذة والسجل المرتبط والتوقيت المحلي.

## السلوك
- يظل المسار `GET /medical-records/access-history` متاحاً لصاحب الملف الطبي فقط.
- يعرض آخر 200 حدث بترتيب الأحدث أولاً.
- تُحوّل أنواع الأحداث التقنية إلى أوصاف عربية مفهومة، وتشمل قراءة الملف والسجلات والوصفات ونتائج التحاليل والتقارير، وقراءة المرفقات وتنزيلها، ومنح المشاركة وإلغائها، وإنشاء السجلات وتعديلها وحذفها.
- يعرض اسم الحساب المنفذ ودوره، دون كشف رقم الهاتف أو البريد الإلكتروني أو معرّف الحساب الخام.
- يعرض عنوان السجل ونوعه عند توفرهما، مع توضيح أن السجل محذوف حالياً دون إعادة محتواه.
- أضيفت واجهة قابلة للطي داخل شاشة «ملفي الصحي» مع تحديث يدوي وعرض التوقيت وفق Asia/Baghdad.
- أحداث تنزيل المرفقات كانت تُسجل مسبقاً في خدمة التنزيل، وتظهر الآن ضمن سجل المريض.
- لا يدّعي السجل تسجيل نشاط غير مدعوم؛ النص التوضيحي يبين أن المعروض هو الأنشطة التي يسجلها النظام.

## الخصوصية
- لا يستطيع الطبيب أو المالك قراءة سجل الاطلاع الخاص بالمريض عبر هذا المسار.
- تُجلب بيانات تعريف محدودة للمنفذين: الاسم الظاهر والدور فقط.
- لا يعرض السجل محتوى التقارير أو الوصفات أو الملفات نفسها.

## الاختبارات
- `scripts_verify_v91.py`: فحوصات تقييد الملكية، تقليل بيانات الهوية، تسميات الأحداث، ربط السجلات، وتوصيل واجهة الهاتف.

## حدود التحقق
هذه فحوصات ثابتة للكود. لم يُنفذ بناء NestJS أو typecheck لـ Expo أو اختبار قاعدة بيانات فعلية/جهاز Android في هذه البيئة؛ ويلزم تنفيذها ضمن بيئة التطوير ذات الاعتماديات قبل النشر.
