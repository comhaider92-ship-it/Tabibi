# V90 — إدارة مشاركة السجلات الطبية بشكل تفصيلي

## الهدف
تمكين المريض من فهم ما يشاركه مع كل طبيب والتحكم في المشاركة على مستوى السجل الواحد أو سحب الموافقة بالكامل.

## السلوك
- يظل عرض قائمة الموافقات وسحب الموافقة كاملة كما في V89.
- يظهر اسم الطبيب واختصاصه وعيادته بدلاً من عرض معرّف حسابه فقط، مع توضيح ما إذا كان ملفه لا يزال معتمداً.
- تعرض كل موافقة السجلات المشمولة بأسمائها وأنواعها وتواريخها وعدد مرفقات كل سجل.
- تفاصيل الأطباء والسجلات تُعاد فقط للمريض صاحب الموافقات، والسجلات المحذوفة أو غير المملوكة له لا تظهر في التفاصيل.
- يظهر إجراء «إلغاء مشاركة هذا السجل فقط» لكل سجل داخل موافقة سارية.
- يتطلب الإجراء تأكيد المريض قبل التنفيذ.
- يزيل الخادم معرّف السجل المحدد فقط من `recordIds`.
- إذا لم يتبق أي سجل ضمن الموافقة، تُعلّم الموافقة تلقائياً بأنها ملغاة باستخدام `revokedAt`.
- لا يمكن تعديل موافقة منتهية أو ملغاة، ولا يمكن للمريض تعديل موافقة لا تخص حسابه.
- ينفذ التعديل داخل معاملة مع قفل صف الموافقة لمنع تعارض عمليات الإلغاء المتزامنة.
- يسجل النظام حدث `share_revoke` في سجل تدقيق الوصول الطبي للسجل الذي أُلغيت مشاركته.
- تبقى صلاحية الطبيب للوصول إلى السجلات الأخرى ضمن الموافقة نفسها كما هي حتى انتهاء الموافقة أو سحبها بالكامل.
- لا يسمح بتنزيل المرفقات للطبيب إلا بوجود موافقة سارية تتضمن إذن التنزيل؛ ويظل إلغاء الموافقة أو انتهاء مدتها مانعاً فورياً للوصول اللاحق.

## واجهات API
- `GET /medical-records/share-consents` يعيد الموافقات مع بيانات الطبيب وملخص السجلات للمريض صاحب الملف فقط.
- `DELETE /medical-records/share-consents/:id/records/:recordId` يلغي مشاركة سجل واحد.
- `DELETE /medical-records/share-consents/:id` يسحب الموافقة بالكامل.

## الاختبارات
- `scripts_verify_v90.py`: فحوصات الإلغاء الجزئي والقفل والمعاملة وسجل التدقيق وربط الهاتف.
- `scripts_verify_v90_metadata.py`: فحوصات عرض بيانات الطبيب والسجلات، حدود الملكية، إخفاء السجلات المحذوفة، حالات الموافقة، وبقاء حماية تنزيل المرفقات.

## حدود التحقق
اجتازت الفحوصات الثابتة 14/14 لفحوصات الإلغاء الجزئي و21/21 لفحوصات تفاصيل المشاركة. لا تتوفر اعتماديات المشروع في بيئة العمل الحالية، لذلك لم يمكن تنفيذ بناء NestJS أو typecheck كامل لـ Expo، كما أن هذه الفحوصات لا تستبدل اختبار API على قاعدة بيانات فعلية أو تجربة Android على جهاز حقيقي.
