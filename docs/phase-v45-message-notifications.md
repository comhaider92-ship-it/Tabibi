# المرحلة V45 – إشعارات الرسائل

- ربط إرسال رسائل الحجز بخدمة الإشعارات الحالية عبر `NotificationsService`.
- حفظ إشعار داخل التطبيق للمستلم، ومحاولة إرساله Push عبر Firebase عند توفر الإعدادات والجهاز المسجل.
- الإشعار يحمل `messageId` ونوع الحجز ومعرّف الحجز المناسب، دون تضمين نص الرسالة الكامل؛ يعرض معاينة لا تتجاوز 120 حرفاً.
- فشل خدمة الإشعارات لا يفشل إرسال الرسالة الأساسية.
- مركز الإشعارات يتعرف على إشعارات الرسائل ويعرض إجراء فتح المحادثة/الحجز. شاشة الوجهة الحالية هي قائمة الحجوزات للمريض ولوحة الطبيب/المالك للطرف المهني.
- لا Migration جديدة؛ يستعمل جدول الإشعارات الموجود.
- لم يتم اختبار Push فعلياً أو بناء APK أو تشغيل قاعدة بيانات حقيقية.
