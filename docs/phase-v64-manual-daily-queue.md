# V64 — قائمة المراجعين اليومية اليدوية (معدّلة بقرار المستخدم)

## السياسة المعتمدة
- المريض يختار يوم المراجعة فقط؛ لا توجد ساعة حضور إلزامية.
- الطبيب أو المنشأة/المختبر يدير المراجعين عملياً وبشكل يدوي خارج حالات التطبيق، بالرجوع إلى قائمة الحجوزات اليومية.
- التطبيق يعرض الحجوزات وبيانات المراجعين حسب صلاحيات مقدم الخدمة، ولا يحتوي على زر استدعاء أو حالات دور.
- لا يرسل التطبيق أي إشعار عند استدعاء المراجع أو اقتراب دوره؛ لا توجد آلية استدعاء إلكترونية.
- حالات الحجز الأصلية فقط تبقى قائمة: مؤكد، مكتمل، لم يحضر، ملغي، وطلبات المنشآت قيد القرار/مؤكد/مرفوض بحسب مسارها.
- إدارة قائمة المراجعين لا تغيّر حالة الحجز ولا صلاحياته.

## إزالة مكونات الدور
- أزيلت واجهات وواجهات API الخاصة باستدعاء التالي وتغيير حالة الدور.
- أزيلت حقول queueStatus وqueueUpdatedAt من كياني appointments وfacility_bookings.
- أضيفت migration لاحقة لإزالة أعمدة وفهارس الدور التي أضافتها migration السابقة؛ لا تعدّل migration السابقة حتى تبقى سجلات الترحيل التاريخية سليمة.
- بقي ترتيب قوائم الحجوزات اليومية ومعلومات المريض والتواصل المعتاد عبر محادثة الحجز.
